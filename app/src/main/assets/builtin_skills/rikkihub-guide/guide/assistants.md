# 助手

助手决定“谁在跟你聊”：名字、提示词、模型、参数，以及它能用哪些扩展和工具。管理入口：`设置 › 助手`；在侧边栏底部点当前助手可以快速切换。设置都是按助手保存的，换一个助手就是另一套。

## 助手列表

- 右上角加号新建；每个助手可以复制、删除（创造助手不能删）。新建时也可以「导入酒馆预设（JSON）」。
- 「标签」给助手分组。「卡片显示设置」里可以写一行「备注」，名字很长时选「单栏整行显示」。
- 「启用」关掉后，这个助手不出现在助手抽屉、“移至助手”和分享列表里，正在用的不受影响。
- 导入 SillyTavern 预设时，连接类设置不会导入，正则脚本以关闭状态导入。助手详情里可以「导出为酒馆预设」。

## 助手详情的几个分区

### 基础设定（模型、参数、背景）

- 「助手名称」、头像；「使用助手头像」：聊天里显示助手的头像和名字，而不是模型的。
- 「聊天模型」：这个助手默认用的模型，不设就用全局默认聊天模型。
- 「温度」「Top P」「最大Token数」「思考预算」；「更多采样参数」里有 Top K、频率惩罚、存在惩罚、重复惩罚、Min P、Top A、种子（Seed），只有支持的服务才生效。
- 「上下文消息限制」：只发最近多少条消息。0 表示不限制。注意：每次因为这个限制裁掉旧消息，提示词缓存就会失效；限制设大些裁得少，不限制就从不裁。
- 「流式输出」：边生成边显示。
- 「每轮标题」：让模型在每条回复末尾写一个短标题，显示在模型名右边，也能被搜索到。
- 「工作区」：绑定后，这个助手可以用工作区的文件和沙盒工具（见[工作区](workspace.md)）。创造助手不能绑定工作区。
- 聊天背景、「背景透明度」、「渐变背景」。

### 提示词（系统提示、消息模板、正则）

- **系统提示词**：可以「整块」写，也可以「分块」写。分块时，开着的块按顺序拼起来发给模型，块的标题只给你自己看。
- 「酒馆模式」：打开后使用完整的提示词布局、角色卡、用户设定、作者注释和组装选项（见[酒馆](tavern.md)）；关闭时是精简布局。
- 「独立对话系统提示」：允许每个对话单独写系统提示。
- 「独立对话提示词库」：允许每个对话单独选择提示词库条目和世界书。
- 「聊天内容模板」：发给模型前怎么包装你的消息，一般不用改；模板里必须保留 `{{ message }}`，否则你的消息发不出去。
- 「预设聊天消息」：对话一开始就有的几条消息（开场白）。
- 「消息正则表达式」：发送前或收到后按正则替换文字；标着“仅视觉”的规则只改显示，不改实际发给模型的内容。

### 扩展管理（快捷消息、提示词库、世界书、Skills）

勾选这个助手能用哪些快捷消息、提示词库条目、世界书和技能。在对话里点输入框下方的「扩展管理」也能改，效果一样。

### 记忆

- 「记忆」：打开后，助手会记住你告诉它的事，之后的对话里会用到。记忆按文件存放，可以在「管理记忆」里查看、添加、编辑、删除。
- 「全局记忆」：改用所有助手共用的一份记忆库。原来这个助手自己的记忆会保留，关掉就切回去；也可以把它们复制或合并到全局记忆。全局记忆在 `设置 › 全局记忆` 管理。
- **做梦**：对话停下来后，在后台把聊天内容整理进记忆。总开关和时机（空闲多久、攒够多少轮、离开对话时、切到后台时、启动时补整理）、用哪个模型、提示词，都在 `设置 › 做梦`。记忆页的「立即做梦」马上整理一次。做梦用的模型需要支持工具调用。
- 「参考历史聊天记录」：允许助手搜索你过去的对话。
- 「时间提醒」：两条消息间隔很久时，自动插一条时间提醒，让模型知道过了多久。

### 自定义请求

给这个助手的请求加自定义 Header 或 Body 字段（JSON），用于服务商要求的特殊参数。不懂就不要动。

### MCP

勾选这个助手能用哪些 MCP 服务器的工具。只能在助手详情里改，对话里的「扩展管理」没有 MCP。服务器本身在 `设置 › MCP` 添加：选「传输类型」（SSE 或流式 HTTP），填服务器地址，需要的话加自定义请求头或做 OAuth 授权；也可以粘贴标准 `mcpServers` 格式的 JSON 导入。保存后能看到它提供的工具，可以逐个设「需要审批」和「并行」。

### 本地工具

App 自带、在手机上执行的工具，按需打开：

- 「询问用户」：允许模型向你提问。
- 「剪贴板」：读写剪贴板里的文字。
- 「JavaScript 引擎」：用 QuickJS 执行 JavaScript，做计算。
- 「时间信息」：当前日期、星期、时间、时区。
- 「文字转语音」：用你选的语音服务朗读。
- 「屏幕时间」：读取应用使用时长，要授予“使用情况访问权限”。
- 「日历」：查询和创建日历事件。
- 「原生图表」：画折线、柱状、散点图和数据表。
- 「伪工具读写」：模型通过 write 工具回复，你的消息作为 read 工具的结果交给它。给特殊场景用，需要支持工具的模型。

模型要有「工具」能力，这些工具才会发给它。

## 全局共用的几样东西

这些在设置里统一管理，再到各个助手里勾选使用：

- `设置 › 快捷消息`：常用的话，点一下填进输入框。
- `设置 › 提示词库`：可复用的提示词片段（以前叫“模式注入”），可以设插入位置（系统提示词前后、对话开头、最新消息前、在某个深度）、角色和优先级。
- `设置 › 世界书`：按关键词触发的设定条目，提到关键词时才把条目内容加进请求。可以设「常驻激活」（不用匹配关键词）、「扫描深度」、「使用正则表达式」、「大小写敏感」。完整的酒馆世界书字段见[酒馆](tavern.md)。
- `设置 › 上下文压缩`：自动压缩的阈值和摘要设置（见[对话](chat.md)）。
- `设置 › 子代理预设`：工作区里“子代理”工具能派出去的工人角色，是全局共用的库，勾选关联到哪些工作区；「全局启用」关掉后已关联的角色也不能运行。

## 技能（Agent Skills）

技能是一个文件夹，里面有 `SKILL.md` 说明书。模型在需要时才读取它，平时只占一行说明。

- 在 `设置 › Agent Skills` 管理：右下角加号可以「手动添加」、「从文件导入」或「从 GitHub 导入」（填仓库地址，支持 `/tree/分支` 和子目录）。
- 标着“内置 · 仅查看”的是 App 自带的技能，例如这份使用指南 `rikkihub-guide`、去八股规则专家 `qubagu-rules`、帮你写技能的 `skill-creator`。想改就复制到用户技能目录，复制品会盖住自带版本（以后 App 更新了自带版本，你的复制品也不会跟着更新）。
- 新建或导入的技能不会自动打开，要在助手的「扩展管理」里勾选。使用指南默认只对创造助手打开。
- 技能需要模型能调用工具。工作区的 CLI 对话目前不会自动带上 App 里的技能。

## 让创造助手代劳

创造助手可以用对话帮你新建助手、改提示词、建世界书和条目、加提供商和模型、写快捷消息、做角色卡等，每项改动都先给你预览，你批准后才生效，之后还能撤销。它管不到的：删除提供商和角色卡、MCP 服务器、工作区、记忆、外观等应用设置，以及它自己。
