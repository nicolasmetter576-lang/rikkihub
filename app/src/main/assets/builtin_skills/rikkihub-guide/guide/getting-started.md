# 第一次用

## 界面速览

- **对话页**是主界面。顶栏中间是对话标题和当前助手、模型；右上角有「新聊天」和「上下文管理」（压缩历史、清空上下文、上下文记录）。
- **侧边栏**：点左上角按钮，或从屏幕左边缘向右滑。里面有「搜索聊天」「聊天历史」、角色卡、对话列表（可以建文件夹）。底部是「AI翻译」「媒体创作」「收藏」「统计」「设置」，再往上是当前助手，点它切换助手。
- **输入框下方**从左到右：
  - 模型按钮：点它换这次对话用的模型；
  - 「上传文件」；
  - 「扩展管理」：给当前助手开关快捷消息、提示词库、世界书、Skills；
  - 「更多选项」（加号）：拍照、照片、草图、网络搜索、推理、提示词、压缩历史、缓存保活、去八股等；
  - 「润色」：先把你写的话润色一遍再发；
  - 「发送」。
- **设置首页**按块分组，顶部的「搜索设置」能按名字直接搜到具体设置项。

## 第一步：添加提供商（模型服务）

App 本身不带模型，要先接入一个提供商（OpenAI 兼容服务、Google Gemini、Anthropic Claude，或各种中转）。

1. 打开 `设置 › 提供商`。列表里已经有常用服务（OpenAI、Gemini、DeepSeek、硅基流动、OpenRouter 等），点进去填 API Key、打开「是否启用」就能用。
2. 列表里没有的：点右上角加号。弹窗顶部有 OpenAI、Google、Claude 三个按钮，选接口协议；再填「名称」「API Base Url」「API Key」，点「添加」。加号只能新建这三种协议的提供商。中转服务一般选 OpenAI，地址填服务商给的、通常以 `/v1` 结尾的地址。
3. 也可以用「导入供应商配置」：扫二维码，或从相册选一张二维码图片。闪光图标是「推荐提供商」。
4. 进入提供商详情：
   - 「配置」页签：地址、Key、高级设置。多把 Key 可以放进“API Key 池”，用「批量粘贴」一次加入；「凭证调度策略」可选「轮询」或「主备顺延」，后者更容易命中提示词缓存。
   - 「模型」页签：点「刷新模型列表」从服务端拉取，在「可用模型」里勾选要用的；也可以点「添加模型」手动填「模型ID」。
5. 点「测试连接」确认能用。可以分别测「流式」「非流式」「工具调用」。工具调用测不过的模型，用不了联网搜索、工作区、技能这类需要工具的功能。

### 模型的几个属性（编辑模型时设置）

- 「模型类型」：「聊天」「嵌入」「图像」。
- 「输入模态」「输出模态」：能不能看图、出图。
- 「能力」：「工具」「推理」。不勾「工具」，模型就不会拿到任何工具；勾了「推理」，加号菜单里才有「推理」，可以调「思考强度」。
- 「上下文长度」：用来显示输入区的上下文用量和自动压缩的判断。
- 「价格（每百万 Token）」：只用来在统计页估算花费和设「消费上限」，可以点「填入参考价」从 models.dev 填入。
- 「提供商重写」：给单个模型单独指定地址或 Key，其余沿用提供商的设置。

### 需要登录的提供商

Codex（OpenAI 账号）、Devin、Antigravity（Google 账号）**已经内置在 `设置 › 提供商` 的列表里，不能用加号新建**。点进去，用详情页里的登录按钮（如「使用 OpenAI OAuth 登录」「使用 Devin OAuth 登录」「使用 Google 登录」）登录账号，不填 Key；可以登录多个账号轮流用，详情页能看到额度和重置时间。这几种依赖对方服务的兼容性，对方一改就可能失效。登录时如果提示本地回调端口被占用，关掉占用端口的应用后重试；Antigravity 和 Devin 也可以把浏览器里的回调地址粘贴进来完成登录。

### 消费上限

提供商详情里可以设「消费上限」（美元，按模型价格估算，没填价格的模型不计）。达到上限后，这个提供商的模型会停用，要回到同一个地方点「解除限制」才能继续用。

## 第二步：设默认模型

`设置 › 默认模型和提示词`，「模型」页签：

- 「聊天模型」：新对话默认用的模型。助手可以另设自己的聊天模型。
- 「快速模型」：生成标题、聊天建议等后台小任务用的模型，可以选便宜快的。
- 「翻译模型」「OCR 模型」：翻译和识图文字用。
- 开关「自动生成对话标题」「启用聊天建议」也在这里。
- 「提示词」页签可以改标题、翻译、聊天建议、OCR 等用的提示词，「重置为默认」可以恢复。

## 第三步：助手

助手是“谁在跟你聊”：名字、提示词、模型、参数和各种扩展的组合。`设置 › 助手` 管理所有助手，详见[助手](assistants.md)。

- 列表里固定有一个「创造助手」：它能通过对话帮你创建和修改助手、世界书、提供商、快捷消息、角色卡等，每项修改都要你在 App 或 Web 端批准后才生效。它删不了提供商和角色卡，也管不了 MCP、工作区、外观等设置。
- 在侧边栏底部点当前助手可以切换。切换后新对话用新助手；`设置 › 常规 › 切换助手时新建对话` 决定是否顺便开一个新对话。

## 第四步：开始对话

在输入框写字发送即可。常用的：

- 换模型：点输入框下方的模型按钮，只影响当前对话。
- 联网：「更多选项」›「网络搜索」，点一下开关，长按选搜索服务（搜索服务要先在 `设置 › 搜索服务` 配好）。
- 推理强度：「更多选项」›「推理」，只有勾了「推理」能力的模型才有。

接下来可以看：[对话](chat.md) 里的消息操作和各种开关；回复报错时看[排查](troubleshooting.md)。

## 安全提醒

- API Key 只填在 App 的设置里，不要发进对话，也不要截图外传。
- 包名是 `me.rerere.rikkihub`，和官方 RikkaHub 不同：两者可以同时安装，但不能互相覆盖安装，数据也不互通。
