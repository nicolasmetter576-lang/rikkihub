# 服务：搜索、语音、媒体、MCP、CC 伪装、缓存保活、网络

都在设置首页的“模型与服务”分组（网络在“外观与交互”分组）。

## 搜索服务

`设置 › 搜索服务`：给不自带搜索的模型提供联网搜索。

- 「添加提供商」选一种服务：Bing、DuckDuckGo、智谱、豆包、Tavily、Exa、SearXNG、LinkUp、Brave、秘塔（Metaso）、Ollama、Perplexity、Firecrawl、Jina、博查（Bocha）、Grok、Serper、DeepSeek 等，也可以用自定义 JS 脚本接自己的搜索接口。大多数要填 API 密钥。
- 「通用选项」里设「结果数量」等。每个服务可以「测试搜索」：输入一句查询，看能不能返回结果。
- 用法：对话里「更多选项」›「网络搜索」点按开关，长按选用哪个服务。模型本身支持搜索（比如 Gemini 勾了内置搜索工具）时，会用模型自带的搜索。
- Gemini 模型可以在提供商详情 › 模型 › 编辑模型 › 「内置工具」里打开搜索、URL 上下文、图像生成。

## 语音服务

`设置 › 语音服务`，分两部分：

- **朗读（TTS）**：OpenAI、Gemini、系统自带 TTS、MiniMax、通义（Qwen）、Groq、xAI、MiMo、ElevenLabs、阶跃（Step）、Fish Audio。选一个设为当前使用的。消息上的「语音」按钮、`设置 › 常规 › 生成后自动播放TTS`、本地工具「文字转语音」都用它。
- **语音识别（ASR）**：OpenAI Realtime、DashScope、火山、MiMo、阶跃（Step）。语音输入和「语音模式」用它；「语音模式」需要支持服务端断句的识别服务（OpenAI Realtime、DashScope 或火山）。
- 朗读相关的偏好在 `设置 › 常规`：默认播放速度、只读引号内的内容、不读括号内的内容、语音模式回复时继续聆听。

## 媒体（图片、视频生成）

`设置 › 媒体`：配置图像和视频生成服务（「添加提供商」选「提供商类型」，再加模型，「模型 ID」原样发给接口）。在侧边栏底部的「媒体创作」里使用。

- 「素材存储」：有些接口只接受公网地址的素材（如视频生成的参考图）。配一个 S3 兼容的对象存储后，本地文件会先上传再发给接口。
- 聊天里直接出图：用输出模态带图片的聊天模型，或 Gemini 的图像生成内置工具。

## MCP

`设置 › MCP`：添加 MCP 服务器，给模型接外部工具。

- 「传输类型」选 SSE 或流式 HTTP，填服务器地址；可以加自定义请求头（比如 `Authorization`）；需要登录的服务器点「OAuth 授权」。
- 也可以粘贴标准 `mcpServers` 格式的 JSON 一次导入。
- 保存后能看到服务器提供的工具，可以逐个设「需要审批」和「并行」。
- 然后到助手详情 › MCP 勾选这个助手能用哪些服务器。工作区 CLI 对话里，MCP 工具会桥接给支持 HTTP MCP 的 CLI 智能体。
- App 只支持远程（HTTP / SSE）MCP 服务器，不在手机上启动本地 MCP 进程。

## CC 伪装

`设置 › CC伪装配置`：把发往 Claude 协议接口的请求伪装成 Claude Code 客户端（身份文本、User ID、User-Agent、x-app、anthropic-beta 等请求头）。这是全局配置，还要在每个模型的「高级设置」里打开「CC伪装」才生效，只对 Claude 协议有效。只在你的服务商要求时使用。

## 缓存保活

`设置 › 缓存保活`：提示词缓存（Claude 等）几分钟没用就会过期。打开「启用缓存保活」后，每次真实请求之后，会在缓存过期前用 1 token 的输出上限把请求重放一次，让缓存保持热的。

- 「保活间隔（秒）」默认 270 秒；「保活上限（分钟）」默认 30 分钟，从最近一次真实请求起算。
- **每次重放都是一次计费请求。** 重放失败、上下文变了、超时或到达上限时停止，等下一次请求再开始。
- 对话里「更多选项」›「缓存保活」可以快速开关，但它和这里是同一个全局开关，不是只对当前对话；输入框上方会显示保活状态。
- Claude 协议的提供商还可以在模型设置里开「提示缓存 (cache_control)」、选「提示缓存时长」（5 分钟或 1 小时）。

## 网络

`设置 › 网络`：

- 「代理」：支持 HTTP 和 SOCKS5 代理地址，留空用系统设置。可以改请求的 User-Agent。用「测试连接」检查。
- 「自动重试」：网络错误时自动重试模型请求，最多 3 次。
- 「限流自动重试」：服务端返回 429 或 503 时等待后自动重发，最多 5 次。
- 证书：Web 服务器的 HTTPS 证书在 `设置 › Web服务器` 管理（见[Web 端](web.md)）。
