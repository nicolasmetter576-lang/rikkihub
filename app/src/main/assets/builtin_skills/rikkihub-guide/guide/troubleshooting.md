# 按症状排查

排查的第一步：问清错误原文和发生在哪一步。需要看请求细节时，请用户打开 `设置 › 请求日志 › 记录请求`，重现一次，看那次请求的状态码和返回内容（鉴权头会自动遮掉）。

## 发不出去 / 一直报错

| 现象 | 常见原因和做法 |
|---|---|
| 401、403、“invalid api key” | Key 填错、过期或没余额。到提供商详情核对 Key，点「测试连接」。多把 Key 时看“API Key 池”里哪把显示“鉴权异常”。 |
| 404、“model not found” | 「模型ID」写错，或这个服务没有该模型。在「模型」页签点「刷新模型列表」重新勾选。 |
| 地址不对 | OpenAI 兼容服务的「API Base Url」通常以 `/v1` 结尾；中转服务以服务商给的地址为准。协议类型选错（比如 Claude 接口选成 OpenAI）也会失败。 |
| 429、503（限流、过载） | 打开 `设置 › 网络 › 限流自动重试` 会等一会儿自动重发，最多 5 次。经常限流可以多加几把 Key（凭证调度会自动换），或换个时间、换模型。 |
| 无法解析服务器地址、连接超时、无法连接到服务器 | 网络或代理问题。检查 `设置 › 网络 › 代理`，用「测试连接」试一下；国内访问海外服务通常需要代理。 |
| 提示达到消费上限、提供商被停用 | 到 `设置 › 提供商` 里对应提供商的「消费上限」点「解除限制」。 |
| 选不到模型，提示“没有可用AI提供商” | 先在 `设置 › 提供商` 添加并打开「是否启用」，再勾选模型。 |
| 标题、聊天建议生成失败 | 「快速模型」没设或不可用：到 `设置 › 默认模型和提示词 › 快速模型` 换一个。 |
| Codex、Devin、Antigravity 失败 | 登录过期：在提供商详情点「重新认证」或「重新登录」；也可能是对方服务改了接口。 |

## 回复不对劲

- **回复只有一半**：消息上注明“已达最大输出长度”时，把助手的「最大Token数」调大或留空；注明“已达最大工具调用步数”时，任务太长，让模型分步做。
- **被内容安全策略中断**：服务商的过滤，换模型或改写请求。
- **回复为空或很怪**：看请求日志里服务端到底返回了什么；推理模型把「温度」改大可能更差，恢复默认试试。
- **模型不记得前面说过的**：可能是助手的「上下文消息限制」太小，或者做过压缩、清空上下文（顶栏「上下文管理」›「上下文记录」能看到，可以撤销）。
- **模型看不到图片**：模型的「输入模态」要包含图片，模型本身也要支持。
- **思考过程不显示**：`设置 › 界面 › 显示思考内容`；模型要勾「推理」能力。

## 工具、搜索、技能不起作用

- 模型要勾「工具」能力，且这个模型真的支持工具调用（提供商详情 › 「测试连接」里测「工具调用」）。
- 联网搜索：对话里「更多选项」›「网络搜索」要打开，`设置 › 搜索服务` 里要有能用的服务（「测试搜索」验证）。
- MCP：服务器在 `设置 › MCP` 里启用，并且在助手详情 › MCP 里勾选。
- 技能：在助手的「扩展管理」›「Skills」里勾选。工作区 CLI 对话目前不会带上 App 里的技能。
- 工作区工具：助手要绑定工作区；工具在工作区详情的「工具启用」里开着。
- 工具卡片一直等着：可能在等你「批准」，或者在等你回答「询问用户」的问题；App 在后台时，悬浮窗也会提示。

## 工作区

- **Rootfs 下载失败**：网络问题，重试，或打开「使用国内镜像」。
- **终端打不开**：试「兼容模式」。
- **基础环境配置失败**：点「日志」看是哪一步失败；只支持 Ubuntu 和 Debian。
- **CLI 提示未安装或需要登录**：点「打开终端（安装 / 登录）」完成安装和登录，或在「管理 CLI 与环境变量」里填 API Key。
- **CLI 会话已中断**：重新发送；原会话丢了时会自动带上前文开新会话。
- **文件在编辑器外被改过**：编辑器会暂停自动保存，不会覆盖。先保留你的修改（复制出来），再重新打开文件。

## 数据与备份

- **恢复备份提示版本不兼容**：备份来自更新的版本时，先把 App 升到同一版本或更新。
- **加密备份打不开**：密码错，或文件损坏。忘了密码无法找回。
- **恢复后不满意**：重启后「撤销本次恢复」。
- **想装回旧版本**：升级后不能降级（数据库结构可能已经变了）。只能用旧版本时做的备份在旧版本里恢复。
- **手机空间不够**：`设置 › 存储管理` 清理聊天附件；本地快照也占空间，可以减少「保留最近份数」。

## App 本身

- **App 打开就崩溃**：下次启动会进入「安全模式」，先「切换助手」试试，再「进入应用」。
- **后台生成被打断、通知不及时**：把 rikkihub 设为不受电池优化限制，并允许通知；部分系统（如 ColorOS）还要允许自启动和后台运行。
- **悬浮窗不出现**：`设置 › 通知 › 后台悬浮窗` 要打开并「授予悬浮窗权限」；点悬浮窗打不开 App 时，在系统设置里允许“后台弹出界面”。
- **Web 端连不上**：见[Web 端](web.md)。

还解决不了：请用户把错误原文、请求日志里那次请求的状态码和返回内容（遮住敏感信息）、App 版本号发出来，再进一步分析。
