# 酒馆（角色扮演）

rikkihub 原生兼容 SillyTavern（酒馆）的角色卡、预设、世界书、正则和宏，不需要另装酒馆。设置首页的“酒馆”分组有 `设置 › 角色`、`设置 › 用户设定`、`设置 › 全局正则脚本`。

## 先打开助手的酒馆模式

角色卡、用户设定、作者注释、完整提示词布局，只在助手打开「酒馆模式」后才生效：助手详情 › 提示词 › 「酒馆模式」。对话绑定了角色但助手没开酒馆模式时，对话页会提示“角色卡不会发送”，旁边有「打开」按钮。

## 角色卡

- `设置 › 角色`（侧边栏顶部也有角色入口）：「导入」PNG、JSON 或 CHARX 角色卡，或「新建角色」。
- 导入时，卡里带的世界书会自动建成一本世界书并挂在角色上；卡里的正则脚本不会自动运行，看过后点「允许脚本」才生效。
- 编辑角色：「名字」「描述」「性格」「场景」「开场白」「备选开场白（新聊天里可滑动切换）」「对话示例」「标签（逗号分隔）」；「高级」里有「主提示词覆盖」「历史之后的指令」「深度提示词（插入聊天中）」。
- 角色还可以挂只在和它聊天时生效的世界书。
- 「开始聊天」会用一个助手开新对话：在角色页顶部能看到是哪个助手，可以换。
- 「导出」成「PNG 角色卡」「JSON 角色卡」或「CHARX 包」。删除角色时可以选「同时删除随卡导入的世界书」。
- 创造助手能新建和编辑角色卡，但不能删除，也不能导入卡文件。

## 用户设定

`设置 › 用户设定`：

- 「名字」：提示词和角色卡里的 `{{user}}` 会换成它，留空就是“user”。
- 「设定描述」：你在故事里是谁，每次请求都会带上。

## 提示词布局（预设）

酒馆模式下，助手的提示词是一串按顺序发送的条目，和酒馆预设一样：

- 灰色的是自动填入的标记（世界书、示例对话、聊天历史、记忆与工具说明、用户设定、角色描述、角色性格、场景、主提示词、历史之后的指令等），只能开关和挪位置。
- 点条目编辑内容；条目还能设角色（系统 / 用户 / 助手）、位置（按顺序，或聊天内某个深度）和发送时机（新消息、重新生成、后台任务，都不选就每次都发）。
- 「保留原文」的条目不会被角色卡自己的文字替换。
- 「组装选项」：历史的 token 预算、为回复预留的 token、合并相邻的系统消息、新对话标记、世界书包装文字等。
- 导入导出：新建助手时「导入酒馆预设（JSON）」；助手详情里「导出为酒馆预设」。

## 作者注释与变量

在对话里点「更多选项」›「作者注释」：

- 「作者注释」：只属于这个对话的备注，每隔几条消息插进提示词一次，用来把握语气或提醒模型某件事。可以选插在「提示词之后」「提示词之前」或「聊天内」；「每 N 条用户消息」填 1 是每次都加，0 是关闭。可以「存为默认值」给所有对话用。
- 「变量」：由 `{{setvar}}`、`{{setglobalvar}}` 设置的值，分本会话和全局，可以手动改，下一次请求起生效。

## 世界书（完整字段）

`设置 › 世界书`。酒馆模式下支持酒馆世界书的全部字段：

- 「基本」：标题 / 备注、关键词（逗号分隔，正则写成 `/模式/标志`）、「次要关键词」和「次要关键词规则」（任意一个命中、全部命中、全部未命中、不是全部命中）。
- 「触发」：「顺序」（数字小的在前，预算不够时数字大的优先保留）、「触发概率（%）」、扫描深度、「整词匹配」、「忽略预算」。
- 「位置」：提示词之前 / 之后、作者注释之上 / 之下、示例对话之上 / 之下、聊天内指定深度、出口（outlet：在提示词条目里写 `{{outlet::名称}}`，文字就放到那里）。
- 「递归」：「不被其他条目触发」「不触发其他条目」「延迟到递归」、递归层级。
- 「分组」：同组条目按权重只选一条；「组内优先」「组权重」「组评分」。
- 「计时」：「粘滞（消息数）」「冷却（消息数）」「延迟（消息数）」。
- 「世界书全局设置」：扫描深度、预算（占上下文的比例）、预算上限、最少激活数、递归扫描、递归步数上限、包含名字、整词匹配默认值等。
- 导出时可选「Rikkihub 文件」或「酒馆世界书文件」（后者能直接导入酒馆）。
- 想知道某条回复用到了哪些条目：在那条消息的「更多选项」里查看。

## 正则脚本

- `设置 › 全局正则脚本`：对所有助手生效，先于助手自己的脚本执行。助手自己的在助手详情 › 提示词 › 「消息正则表达式」。
- 每个脚本可以选作用于「用户输入」「AI 输出」「世界书」「推理」；查找写成 `/模式/标志`，替换里用 `$1` 或 `$<名称>` 引用捕获内容，也能用宏。
- 「仅显示」只改界面上看到的文字；「仅提示词」只改发给模型的内容；两者都不改已存的消息。「编辑时运行」：编辑消息后也运行。可以设深度范围，只作用于最近几条消息。
- 「试运行」：输入示例文字看效果。

## 宏

常用的 `{{user}}`、`{{char}}`、`{{persona}}`、`{{setvar}}` / `{{getvar}}`、`{{outlet::名称}}` 等酒馆宏都能用，写法和酒馆一致。

## 让创造助手帮忙

创造助手懂这些酒馆对象：可以让它根据你的描述写角色卡、批量建世界书条目（一次最多 200 条）、改提示词条目、加正则脚本、改全局酒馆设置和作者注释默认值。每项改动都要你批准。
