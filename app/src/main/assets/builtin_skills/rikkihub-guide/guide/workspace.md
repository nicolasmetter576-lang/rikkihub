# 工作区

工作区是手机上的一个文件夹，加上一个可选的 Linux 环境（Ubuntu，跑在沙箱里，不需要 root）。助手绑定工作区后，模型就能读写里面的文件、执行命令、派子代理干活。写小说用的“作品模式”也是一种工作区，见[写作](writing.md)。

## 新建与绑定

1. `设置 › 工作区` › 「创建工作区」：填「名称」，选模式：
   - 「标准」：在 Linux 环境里用文件、命令行和子代理工具。
   - 「作品」：写书用，有目录、章节、字数，工具和提示词偏向写作，不装 Linux 也能用（终端除外）。
2. 让助手用它：助手详情 › 基础设定 › 「工作区」选这个工作区；或者在对话里「更多选项」最下面的工作区区域绑定。创造助手不能绑定工作区。

绑定后，对话页会多出几样东西：输入框旁的终端按钮（装了 Linux 才有）、顶栏的工作区 CLI 按钮；从屏幕右边缘向左滑打开工作区文件。

## 工作区详情

`设置 › 工作区` 点进某个工作区，分「基本」「文件」等页签（作品模式的工作区还有「作品」）。

### Linux 环境

- 「安装 Rootfs」：下载并解压 Ubuntu。之后点「基础环境」›「配置」一键装常用软件：基础工具（curl、git、ripgrep 等）、Python 3、Node.js 24 LTS，另可选文档处理（pandoc 等）、中文字体、音视频与图片（ffmpeg、ImageMagick）、编译工具、SQLite 与 SSH，以及 CLI 智能体 Antigravity（agy）和 Factory Droid（droid）。基础那几样约 450 MB。国内网络可以打开「使用国内镜像」。
- 基础环境配置只支持 Ubuntu 和 Debian。
- 终端打不开时试试「兼容模式」（会慢一些）。
- 「重新安装 Rootfs」会重装系统目录。

### AI 工具

- 「Rikkihub 工具」：默认的一套文件和命令工具（读取文件、写入文件、编辑文件、执行命令等）。
- 「Harness 工具」：给 DeepSeek 等模型用的精简工具集，只保留「持久 bash」和「str_replace_editor」。
- 「工具启用」：逐个关掉不想给模型的工具；「工具审批」：调用前需要你确认。配置坏了可以「重置工具启用」。
- 「子代理」：模型可以把有边界的任务派给子代理（嵌套的工人，工人不能再派子代理）。可以单独选「子代理模型」（留空用父对话的模型，只列出支持工具调用的模型）；「允许传入 context」决定父模型能不能把摘录传给工人。子代理的角色来自 `设置 › 子代理预设`。
- 「首条消息附带文件列表」：对话第一条消息自动附上工作目录的文件列表，省得模型先 ls，「列表层数」控制列几层。

### Agent 可见目录

打开开关后模型才看得到这些全局目录：`/upload`（App 里上传的聊天附件）、`/skills` 和 `/builtin_skills`（用户技能和内置技能，内置的只读）、`/tool_outputs`（超长工具结果的完整备份）。

### 设备目录（高风险）

「设备目录」可以把手机上的真实目录连进工作区（需要 Android 11 以上，并授予“所有文件访问”权限）。**模型对它的写入和删除直接作用于原文件，没有统一的回滚，也不在 App 备份里。** 「解除连接」只删连接配置，不动原目录。

## 终端

装了 Linux 后，对话输入框旁的终端按钮或工作区详情能打开终端，可以开多个标签页。CLI 智能体的安装和登录也在终端里做。

## 工作区 CLI（持久会话）

可以让对话直接由工作区里的 CLI 智能体（比如 agy、droid，或你自己添加的支持 ACP 的程序）来回答，而不是走 App 里配置的模型接口。

- 对话顶栏点工作区 CLI 按钮：选一个 CLI，或「关闭（普通对话）」。CLI 运行后（发出第一条消息后）可以在这里选它的模型、模式、思考强度，「重启 CLI 会话」。
- 「审批」：「逐项确认」或「全部自动允许」CLI 的文件和命令操作。
- 「新对话默认使用此 CLI」：这个助手之后的新对话都用 CLI；助手详情里可以「关闭默认 CLI」。
- 「管理 CLI 与环境变量」：「添加自定义 CLI」，填可执行文件、参数、环境变量、登录命令、安装命令。程序要通过 stdio 支持 ACP。把 API Key 填进环境变量（如 `GEMINI_API_KEY`）可以免去终端登录。
- CLI 对话里，App 的模型参数、世界书、完整酒馆布局、记忆、本地工具都不生效；提示词库只传启用的纯文本条目；MCP 工具会桥接给支持 HTTP MCP 的 CLI；App 里的技能目前不会自动带上。压缩历史要在对话里发 `/compact`，由 CLI 自己压缩。
- 角色对话不能用工作区 CLI。

## 对话的工作目录

在对话里可以把工作目录设到工作区的某个子文件夹（「设为CWD」），打开「仅此目录」后模型只看得到这个目录。

## 文件与编辑器

- 工作区的「文件」页签，或在对话里从右边缘滑出文件面板：浏览、「新建」文件或文件夹、导入文件或文件夹、多选后删除、「移动」或「复制到…」（可以跨工作区，同名自动加序号）、「导出 ZIP」、「导出到文件夹」、「解压」（zip、7z、rar、tar、gz、bz2、xz，支持密码和文件名编码）。
- **编辑器**：点文本文件打开。可以在「源码」和「预览」之间切换；快捷栏有标题、粗体、斜体、列表、引用、任务、链接、代码、表格、撤销、重做；「查找」支持替换、全部替换和区分大小写；「排版」可以统一段间空行、段首缩进、中英文之间加空格；「对照」可以把另一篇文件放在旁边看。
  - 自动保存；文件在编辑器外被改过时会暂停保存，不会覆盖，让你选择怎么处理。「还原」回到打开时的版本，之后还能撤销找回修改。
  - 编辑器的字体、字号、行距，快捷栏的位置（顶部或底部）、布局（单栏或多栏）、尺寸、按钮顺序和每个按钮的开关，以及自动补全成对符号，都在 `设置 › 编辑器`。
- **阅读模式**：按章翻页阅读，`设置 › 编辑器 › 翻页方式` 选左右翻页或上下滚动，可以用音量键翻页。
- 选中文字后还可以用「推敲」「再造」「去八股」（见[写作](writing.md)）。

## 全局文件管理器

`设置 › 文件管理器`：浏览「聊天上传」的附件、「文件库」、各个工作区，以及授予“所有文件访问”权限后的手机存储。支持按文件名搜索（`*` 和 `?` 是通配符）、压缩、解压、用其他应用打开、属性。Android 系统不允许访问其他应用的 Android/data 和 Android/obb 目录。

## 常见问题

- **终端或命令跑不起来**：先确认 Rootfs 已安装（状态“就绪”），再试「兼容模式」。
- **模型说没有工具**：确认助手绑定了工作区、模型勾了「工具」能力、对应工具在「工具启用」里开着。
- **删除工作区**会删掉里面的所有文件（设备目录的原文件不受影响），先导出需要的东西。
