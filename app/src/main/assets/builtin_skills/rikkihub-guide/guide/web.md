# Web 端

手机上的 rikkihub 可以开一个网页服务，同一网络里的电脑、平板用浏览器打开就能聊天、改设置、管理工作区文件。数据都在手机上，网页只是另一个界面，所以手机上的 App 要保持运行（服务运行时通知栏会显示“Web服务器运行中”）。

## 打开

1. `设置 › Web服务器`：点「启动」。
2. 页面上会列出访问地址：
   - 「局域网地址」：手机的 Wi-Fi IP，同一网络里的设备用它访问（手机用移动数据时一般访问不了）；
   - 「mDNS地址」：部分系统可以用 `.local` 名字访问；
   - 「本机地址」：只有手机自己能访问。
3. 在电脑浏览器里打开这个地址。

## 安全设置

- 「启用身份验证」并设「访问密码」：**同一网络里的人都能打开这个地址，建议一定设密码**。
- 「仅本地主机」：只监听 127.0.0.1，局域网和 mDNS 都会关掉。
- 「端口」：默认端口被占用时可以换（1024–65535）。
- 「HTTPS」：用 App 自己生成的本地证书提供 HTTPS。浏览器第一次会提示证书不受信任：先「导出公开 CA 证书」装到电脑上并信任，登录前把浏览器显示的证书指纹和本页的「CA 证书 SHA-256 指纹」核对一致。只信任这张证书，不要全局关闭浏览器的证书校验。
- 「轮换本地证书」：换一张新证书，会停止服务、让现有网页登录失效，需要重新信任新证书。

## 能做什么

- **对话**：和 App 一样聊天、看工具调用、批准工具、压缩历史和上下文管理、排队发消息、编辑消息。
- **设置**（网页左上进入 `Web › 设置`）：助手、提供商、扩展（快捷消息、提示词库、世界书）、技能、子代理预设、缓存保活、工具执行、润色、全局记忆、上下文压缩、统计；酒馆分组的角色、用户设定；写作分组的推敲、再造、去八股、作品。
- **工作区**：浏览和编辑文件、作品模式的目录、全书查找替换、导入导出、反向大纲、节拍写作、版本历史与回收站（找别称除外；网页端不能删版本、不能清空）。网页编辑器有自己的字体排版设置（编辑器里的“Aa”按钮）。
- **创造助手的提案**可以在网页上批准。
- 文件、存储、翻译页面。

## 只能在 App 里做的

- 数据备份与恢复、本地快照、备份加密。
- 搜索服务、语音服务、媒体、MCP、CC 伪装、网络代理的配置。
- 主题、界面、通知、悬浮窗、App 编辑器的快捷栏等外观设置。
- 需要登录的提供商（Codex、Devin、Antigravity）的账号登录。
- Linux 环境安装、终端、设备目录连接。
- Web 服务器本身的设置。

## 连不上时

- 电脑和手机要在同一个 Wi-Fi，路由器没有开“AP 隔离”。
- 手机切到后台太久，系统可能冻结 App：把 rikkihub 设为不受电池优化限制。
- 开了 HTTPS 却用 `http://` 打开（或反过来）会失败，按页面上显示的地址原样输入。
- 浏览器提示证书错误：按上面的步骤信任导出的 CA 证书，并核对指纹。
