# 对话

## 发消息

- 写好点「发送」。`设置 › 常规 › 按Enter发送` 打开后回车直接发送。
- **生成中还能继续发**：新消息会排队（输入框上方显示“待发送 · N”），这一轮结束后自动发出；排队的消息可以编辑或「撤销」。队列因为出错暂停时，点「继续发送」。
- **附件**：「上传文件」选文件；「更多选项」里有「拍照」「照片」「草图」（手画一张图发给模型）。用 Google 提供商时还能发「视频」「音频」。模型要支持看图才能处理图片。
- `设置 › 常规 › 粘贴长文本为文件` 打开后，超过「文本长度阈值」的粘贴内容会变成附件，不挤占输入框。
- 「润色」（输入框右边）：先让模型把你写的话改顺再发送，可以「撤销润色」。用哪个模型、要不要带上对话上下文，在 `设置 › 润色` 里设置。

## 每条消息上的操作

消息下方的按钮：「复制」「重新生成」、助手消息上的「语音」（朗读）、「翻译」，以及「更多选项」。「更多选项」里有：

- 「选择复制」：只复制一部分；「网页视图渲染」：用网页方式显示复杂的 HTML 内容。
- 「编辑」：改消息内容（助手消息也能改）；「编辑标题」：改这一轮的标题（助手开了「每轮标题」时）。
- 「分享」：进入多选，默认选中从对话开头到这条的所有消息，可以再勾选或取消，然后导出成图片或 Markdown，可选是否包含思维过程。
- 「创建分支」：从这条消息分出一个新对话。
- 「添加收藏」：之后在侧边栏「收藏」里找到。
- 「去八股」：对这条回复单独跑一次去八股清理。
- 酒馆模式下还能查看这一轮用到了哪些世界书条目。
- 「删除」。

**重新生成和分支**：重新生成会保留原来的回复，消息下方出现左右箭头，可以在几个版本之间切换；后面的对话跟着所选版本走。重新生成用户消息时会提示：这条之后的消息会被清除。

## 回复里的其他东西

- **思考过程**：推理模型的思考显示在回复上方，可以折叠。`设置 › 界面 › 显示思考内容`、`设置 › 界面 › 自动折叠思考` 控制显示方式。
- **工具调用**：模型调用工具（搜索、读写文件等）时显示成卡片，点开能看参数和结果。需要你确认的工具会出现「批准」「拒绝」，拒绝时可以写原因。「询问用户」工具会让模型向你提问，回答后它再继续。
- **停止原因**：回复因为达到最大输出长度、被内容安全策略拦截、达到最大工具调用步数，或者提前结束时，消息上会注明，这时回复可能不完整。
- **用量**：`设置 › 界面 › 显示Token和上下文统计` 打开后，消息下方显示上下文、缓存、输出的 token 数，点开看每一步的明细和速度。
- **自动重试**：网络错误和限流（429/503）会自动重试，消息上显示“正在重试（n/N）”。开关在 `设置 › 网络 › 自动重试` 和 `设置 › 网络 › 限流自动重试`。一个提供商配了多把 Key 时，失败的 Key 会自动换下一把。

## 顶栏

- 中间是标题和当前助手、模型。点标题可以「编辑标题」。
- 列表图标：切换成消息概览，可以搜索并跳到某条消息。
- 「新聊天」。
- 「上下文管理」：
  - 「压缩历史」：用模型把前面的对话写成一份摘要，之后只发摘要和最近的消息。可以设「保留最近的消息数」，写下“这次希望重点留下的内容”，打开「生成后先给我看」先审再「采用」；也可以选「压缩并新建对话」，原对话不变。压缩后原消息仍然在界面上，只是不再发给模型；删掉摘要就恢复发送完整历史。
  - 「清空上下文」：插一条分隔线，线以上的内容不再发给模型（界面上保留）。
  - 「上下文记录」：历次压缩和清空的记录，可以「撤销」。
  - 「上下文构成」：这次请求里系统提示词、工具、历史各占多少。
- 自动压缩：`设置 › 上下文压缩` 里设「自动压缩」「用量达到」多少时压缩、「压到」多少、用哪个「压缩模型」、「摘要模板」等。上下文用量快满时，输入框上方也会提示“建议压缩”。
- 工作区助手的对话：顶栏多一个工作区 CLI 按钮；从屏幕右边缘向左滑打开工作区文件。

## 「更多选项」（输入框加号）

- 顶部显示当前上下文用量，点「上下文构成」看明细。
- 「网络搜索」：点按开关，长按选择搜索服务。模型自带搜索能力时用模型内置搜索，否则用 `设置 › 搜索服务` 里配置的服务。
- 「推理」：调这个助手的「思考强度」（模型要有「推理」能力）。
- 「提示词」：开关当前助手的提示词条目；长按进入助手设置。
- 「压缩历史」：同上；长按看「上下文构成」。
- 「缓存保活」：点按开关，长按进入设置（见[服务](services.md)）。
- 「去八股」：点按全局开关，长按进入去八股设置（见[写作](writing.md)）。
- 「语音模式」：免手动的语音对话，你说完自动发送，回复朗读完继续听。只有在 `设置 › 语音服务` 选好支持服务端断句的语音识别（OpenAI Realtime、DashScope 或火山）后才会出现；CLI 对话里没有。
- 「作者注释」：这个对话的作者注释和变量（酒馆功能，见[酒馆](tavern.md)）。
- 最下面是工作区区域：绑定或查看这个助手的工作区（见[工作区](workspace.md)）。

## 「扩展管理」（输入框下方的盒子图标）

四个页签：「快捷消息」「提示词库」「世界书」「Skills」，勾选后对**当前助手**生效（不是只对这一个对话）。快捷消息是存好的常用话，点一下填进输入框；在 `设置 › 快捷消息` 里建。提示词库和世界书见[助手](assistants.md)；技能（Skills）也在这里开关，包括这份使用指南 `rikkihub-guide`。

## 对话列表与历史

- 侧边栏列出对话。长按一个对话：「置顶聊天」「重新生成标题」「移至助手」（交给另一个助手）「移动到文件夹」「删除」。文件夹用对话列表上方的「新建」建立。「排序方式」可以换排序。
- 「聊天历史」页可以搜索消息、多选删除、「删除全部」（不可撤销）。
- 「搜索聊天」按标题和内容找对话。
- 助手打开「独立对话系统提示」后，每个对话可以单独写「对话系统提示」，覆盖助手的系统提示。

## 其他页面

- 「AI翻译」（侧边栏底部）：独立的翻译页，有翻译历史；用 `设置 › 默认模型和提示词` 里的「翻译模型」。
- 「媒体创作」：用图像、视频模型生成图片和视频，模型在 `设置 › 媒体` 里配置。
- 「收藏」：收藏过的消息。
- 「统计」：各模型、提供商的用量和估算花费（价格要在模型上填过）。

## 后台、通知和悬浮窗

- `设置 › 通知 › 生成消息后启用通知`：切到后台时回复完成会通知；`设置 › 通知 › 实时更新通知` 在通知里显示“思考中 / 正在运行工具 / 正在编写回复”。
- `设置 › 通知 › 后台悬浮窗`：App 在后台时显示一个悬浮窗，能看进度、快速回复、批准工具调用、回答模型的提问。需要「授予悬浮窗权限」。`设置 › 通知 › 贴边自动隐藏`、`设置 › 通知 › 悬浮窗不透明度` 调外观。点悬浮窗打不开 App 时，到系统设置里允许本应用“后台弹出界面”。

## 显示与操作习惯

- `设置 › 界面`：头像、气泡、模型名、日期时间、代码块换行和行号、LaTeX、引号内文字高亮、聊天字体和字号、长用户消息折叠等。
- `设置 › 常规`：启动或切换助手时是否新建对话、消息导航按钮、自动滚动、触觉反馈、音量键翻页、朗读相关（播放速度、只读引号内内容、不读括号内内容、生成后自动朗读）。
- `设置 › 主题`：颜色模式、动态颜色、主题、AMOLED 暗色。
- 助手还可以设聊天背景、渐变背景（见[助手](assistants.md)）。
